# MADARA_BOT Pair Code

واجهة عربية بسيطة لتوليد رمز ربط لحساب واتساب تملكه أنت، باستخدام Node.js وExpress وBaileys.

## متطلبات النشر

- Node.js 20 أو أحدث.
- خدمة Render من نوع Web Service.
- قرص دائم (Persistent Disk) لحفظ بيانات الجلسة بعد الربط. ملف `render.yaml` يحدد خطة مدفوعة لأن القرص الدائم ليس متاحًا مع خدمات Render المجانية.
- لا ترفع مجلد `auth_info` أو بيانات الجلسة إلى GitHub.

## النشر على Render

1. ارفع محتويات هذا المشروع إلى مستودع GitHub جديد باسم `MADARA_BOT_PairCode`.
2. في Render اختر **New → Blueprint** واربط المستودع، أو أنشئ Web Service يدويًا.
3. الإعدادات اليدوية:
   - Runtime: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
   - أضف قرصًا دائمًا على المسار `/data`
   - أضف متغير البيئة `AUTH_DIR=/data/auth_info`
4. انتظر اكتمال النشر وافتح رابط الخدمة.

## ملاحظات مهمة

- هذا المشروع نموذج أولي؛ اختبره أولًا بحسابك فقط.
- رمز الربط حساس. لا ترسله لأي شخص ولا تطلب رمز شخص آخر.
- توجد حماية أولية تحدّ عدد الطلبات لكل عنوان IP، لكنها ليست بديلًا عن حماية إنتاجية كاملة.
- يجب إبقاء الخدمة شغالة بعد الربط حتى تبقى جلسة واتساب متصلة. خدمات الاستضافة المجانية قد تتوقف عند الخمول ولا توفر قرصًا دائمًا.
- Baileys مكتبة غير رسمية وتتأثر بتغييرات واتساب؛ قد يحتاج المشروع إلى تحديث إذا تغيّر بروتوكول الربط.
- إذا فشل التوليد، افتح Logs في Render للحصول على الخطأ الفعلي. لا تشارك ملفات الجلسة أو بيانات المصادقة.
